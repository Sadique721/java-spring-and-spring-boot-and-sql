## ⚡ Quick Start

### Prerequisites

```bash
# Required
Java 21+         # https://adoptium.net/
Node.js 20+      # https://nodejs.org/
Maven 3.9+       # https://maven.apache.org/
Docker Desktop   # https://docker.com/
Angular CLI 18+  # npm install -g @angular/cli
```

### 🚀 Step-by-Step Setup

#### 1️⃣ Clone the Repository
```bash
git clone https://github.com/Sadique721/java-spring-and-spring-boot-and-sql.git
cd java-spring-and-spring-boot-and-sql
```

#### 2️⃣ Start PostgreSQL (Docker)
```bash
docker-compose up -d
# PostgreSQL starts on localhost:5432
# Database: springmastery | User: admin | Password: admin123
```

#### 3️⃣ Build & Run Backend
```bash
cd backend
mvn spring-boot:run
# Server starts on http://localhost:8080
# Flyway auto-runs migrations
# Database seeds 13,248+ sections automatically
```

#### 4️⃣ Build Frontend (Angular → Spring Boot static)
```bash
cd frontend
npm install
npm run build
# Output → backend/src/main/resources/static/
# Restart backend if already running
```

#### 5️⃣ Access the App
```
🌐 App:       http://localhost:8080
📊 Dashboard: http://localhost:8080/dashboard
🧠 Graph:     http://localhost:8080/graph
❤️ Health:    http://localhost:8080/actuator/health
```

### 🐳 Docker Compose Reference

```yaml
# docker-compose.yml
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: springmastery
      POSTGRES_USER: admin
      POSTGRES_PASSWORD: admin123
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
```

## 🗄️ Database Schema

```sql
-- Core Learning Structure
modules          (id, title, slug, description, display_order)
    └── topics   (id, module_id, title, slug, difficulty, estimated_minutes)
        └── sections              (id, topic_id, section_number, section_title, content)
        └── quiz_questions        (id, topic_id, question, options[], correct_answer_index, explanation)
        └── code_examples         (id, topic_id, title, code, explanation, level)
        └── interview_questions   (id, topic_id, question, answer, difficulty, category, interview_tip)
        └── revision_notes        (id, topic_id, content, key_points[], memory_tricks[])

-- Progress Tracking
learning_progress (id, session_id, topic_id, status, quiz_score, completion_percentage)

-- Knowledge Graph
knowledge_graph_edges (id, source_topic_id, target_topic_id, relationship_type, weight)
```

## 🔧 Configuration

```properties
# backend/src/main/resources/application.properties

# Database
spring.datasource.url=jdbc:postgresql://localhost:5432/springmastery
spring.datasource.username=admin
spring.datasource.password=admin123

# JPA / Hibernate
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=false

# Flyway
spring.flyway.enabled=true
spring.flyway.locations=classpath:db/migration

# Server
server.port=8080

# Actuator
management.endpoints.web.exposure.include=health,info,metrics
```
